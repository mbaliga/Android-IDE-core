# desktop/core-host/mapping.txt -- the ONE place the host lane's source mapping is declared.
#
# Read by BOTH build.gradle.kts (srcDir + exclusion filter) and desktop/scripts/*.py (so the
# test-count reconciliation and PORTABILITY.md are derived from exactly the files Gradle compiles,
# with no second copy of the list to drift). Plan reference: docs/PORTING_PLAN.md section 6.1, LX-1.
#
# Line format (fields separated by " | ", paths are repo-root-relative, '#' starts a comment):
#   main-root    | <directory>
#   test-root    | <directory>
#   main-exclude | <file> | <witness> | <reason>
#   test-exclude | <file> | <witness> | <reason>
# The witness is a literal string that MUST still occur in the excluded file. If it does not (the
# back-edge was removed, e.g. by plan step LX-3), `./gradlew :core-host:verifyMapping` fails and
# says "delete this exclusion" -- an exclusion can never silently outlive its reason or point at a
# file that no longer exists.

# --- source roots -------------------------------------------------------------------------------
# Package-by-directory is not required by Kotlin, so the roots are the package directories
# themselves. core-engine/src/main/java/dev/fonebrew/domain is the whole domain/ tree; the contract
# corpus is the same ../contracts/kotlin root :core-engine already adds as an extra srcDir.
main-root | core-engine/src/main/java/dev/fonebrew/domain
main-root | contracts/kotlin
test-root | core-engine/src/test/java/dev/fonebrew/domain
